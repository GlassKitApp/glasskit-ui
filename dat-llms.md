# Wearables developer documentation
Product: all
Documentation version: v1.0
Platforms: android, ios_swift, web
Choose by where your code runs: in an iOS or Android phone app (Device Access Toolkit), or in the browser on Meta Ray-Ban Display glasses (Web Apps). Only the Device Access Toolkit can use the glasses' camera or capture microphone audio; Web Apps get speech only as dictated text.
## Continue
- [Meta Wearables Device Access Toolkit](/llms.txt?product=all&version=1.0&document=products/dat): For iOS and Android apps that connect to supported AI glasses to use their camera, microphones and speakers, and the display on Meta Ray-Ban Display glasses.
- [Web Apps for Meta Ray-Ban Display glasses](/llms.txt?product=all&version=1.0&document=products/webapps): For web apps, served over HTTPS, that run in the Chromium-based browser on Meta Ray-Ban Display glasses.
